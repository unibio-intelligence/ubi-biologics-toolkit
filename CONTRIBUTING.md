# Contributing

Use the contributor setup in README.md. Run Python and TypeScript suites,
regenerate SDKs without changes and build the packages affected by your change.
Fixes enter private authoritative development before a selected public export.
Do not maintain separate implementations of platform operations in the clients.
Use the canonical hosted API/MCP contracts and preserve preview receipts,
idempotency, safe errors and account authorization. Do not add standalone models
or solvers here; their maintained distribution is QSPQuest.

Never include credentials, customer inputs, paper assets or private runtime
code in examples. Source-manifest changes must identify upstream hashes and
transformations. CI verifies without publication or paid hosted execution.
